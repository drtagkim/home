1. 프로젝트 개요 (Overview)

고양이 테트리스(Cat Tetris)는 고전적인 테트리스 게임 플레이 방식에 현대적인 웹 기술과 귀여운 고양이 테마를 결합한 웹 기반 게임입니다.

핵심 목표:
  • 단순한 웹 게임을 넘어선 프리미엄한 사용자 경험(UX) 제공
  • 이중 언어(한국어/영어) 실시간 전환 지원
  • HTML5 Canvas API를 활용한 고성능 렌더링
  • 모바일 및 데스크탑 환경을 고려한 반응형 디자인

개발 변천사 (Evolution)

이 프로젝트는 세 단계의 진화를 거쳤습니다:

  1. 초기 단계: Chrome Extension (Action Button Config) - 폐기됨
  2. 중기 단계: Neon Tetris (사이버펑크 스타일) - 독립 실행형으로 전환
  3. 최종 단계: Cat Tetris (현재 버전) - 따뜻한 파스텔톤과 캐릭터 중심 디자인

2. 기술 아키텍처 (Architecture)

프로젝트는 외부 라이브러리 의존성 없이 Vanilla HTML, CSS, JavaScript만으로 구축되었습니다. 이는 게임의 로딩 속도를 최적화하고 코드의 투명성을 보장합니다.

파일 구조 (File Structure)

핵심 기술 스택

  • HTML5 Canvas: requestAnimationFrame을 사용한 60FPS 게임 루프 구현.
  • CSS Variables: 테마 색상 및 스타일의 중앙 집중식 관리.
  • Local Storage (예정): 사용자 점수 및 설정 저장용.

3. 소스 코드 심층 분석 (Code Deep Dive)

A. 게임 루프와 시간 제어 (Game Loop)

script.js의 핵심은 update() 함수입니다. 이 함수는 프레임마다 호출되며 게임의 상태를 갱신합니다.


// 시간 기반 업데이트를 통한 프레임 속도 독립성 보장
function update(time = 0) {
    if (isPaused || isGameOver || !gameStarted) return;
    
    // 이전 프레임과의 시간 차(deltaTime)를 계산
    const deltaTime = time - lastTime;
    lastTime = time;

    // 누적 시간이 설정된 간격(dropInterval)을 넘으면 블록 하강
    dropCounter += deltaTime;
    if (dropCounter > dropInterval) {
        playerDrop();
    }

    draw(); // 캔버스 다시 그리기
    animationId = requestAnimationFrame(update);
}

B. 스프라이트 렌더링 시스템 (Sprite Rendering)

단순한 색상 블록 대신 이미지를 사용하며, Grid 형태와 Strip 형태의 스프라이트 시트를 모두 지원하는 지능형 렌더링 로직을 구현했습니다.


// 이미지의 가로세로 비율(Assets Aspect Ratio)을 분석하여 레이아웃 자동 감지
const ratio = spriteSheet.width / spriteSheet.height;
if (ratio >= 6) {
    spriteLayout = 'strip'; // 7x1 가로 스트립 (고양이 7마리 일렬)
} else {
    spriteLayout = 'grid'; // 3x3 그리드 형태
}

// 렌더링 시
function drawBlock(ctx, x, y, value) {
    // ...계산된 sx, sy 좌표로 캔버스에 이미지 조각 그리기
    ctx.drawImage(spriteSheet, sx, sy, sw, sh, x, y, 1, 1);
}

literal.js에 언어팩을 정의하고 DOM 요소의 ID와 매핑하여 실시간 전환을 구현했습니다.


const LABELS = {

function updateText() {
    // 매핑 테이블을 순회하며 DOM 텍스트 업데이트
    for (const [id, key] of Object.entries(map)) {

4. 디자인 및 에셋 (Design & Assets)

사용자 경험의 핵심인 "귀여움"을 기술적으로 구현하기 위해 다음과 같은 전략을 사용했습니다.

Liquid Cat Concept

"고양이는 액체다(Cats are Liquid)"라는 인터넷 밈에서 착안하여, 테트리스 블록(상자) 안에 꽉 끼어있는 고양이의 모습을 형상화했습니다. 이는 사각형 블록이라는 게임의 제약조건을 캐릭터성과 연결한 기획입니다.

CSS Glassmorphism & Wood

따뜻한 감성을 위해 wood-panel 클래스로 나무 질감을 표현하고, overlay 요소에는 반투명한 블러 효과(backdrop-filter가 아닌 rgba 투명도 활용)를 사용하여 모던함을 더했습니다.
